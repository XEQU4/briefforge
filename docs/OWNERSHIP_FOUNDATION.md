# Ownership foundation

This document records the early ownership-schema milestone. It is retained as historical context, not as the current access-policy specification.

BriefForge records users, organizations, and organization/team memberships, with nullable owner references retained for legacy tasks and proposals. Subsequent phases added session authentication and backend membership enforcement. New organization tasks and team proposals use authenticated ownership; legacy unowned demo records do not grant workspace access.

See [API_CONTRACT.md](API_CONTRACT.md) for current authorization rules and [the root README](../README.md) for the implemented product scope.
